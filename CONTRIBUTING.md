# Contributing

Thanks for looking! Venus is my learning project, so here's how help works
best.

## Welcome

- **Bug reports.** Open an issue: what you did, what you expected, what
  happened, your OS (Windows or Linux), and the end of
  `apps/node/data/venus-node.log` if the PC app is involved. Remove any
  keys, tokens or passwords first.
- **Ideas.** Open an issue and say what you'd use it for.
- **Setup trouble.** If the [install guide](guide/install.md) lost you
  somewhere, tell me where. That's a bug in the guide.

## Pull requests

PRs are welcome, but please know:

- I'm still learning, and I want to understand every change before it goes
  in. Reviews may be slow, and I might ask a lot of questions.
- I may say no to something that's good, just because it doesn't fit where
  I'm taking Venus. For anything bigger than a small fix, open an issue
  first so we can talk about it.
- Keep it small: one fix or feature per PR.
- Run the tests ([developing guide](guide/developing.md#tests)). CI runs
  them on Windows, Linux and macOS too.
- Never commit `.env` files, keys, or your own 3D models and voices.

Security problems: please don't open a public issue, see
[SECURITY.md](SECURITY.md).
