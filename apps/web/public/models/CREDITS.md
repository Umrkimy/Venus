# 3D model credits

`avatar-sample-a.vrm` is **AvatarSample_A**, an official VRoid sample model
by **pixiv Inc.**:
https://hub.vroid.com/en/characters/2843975675147313744/models/5644550979324015604

Conditions of use (checked 2026-10-11): VRoid Hub shows avatar use,
redistribution, alterations and commercial use all allowed, attribution not
required. pixiv's sample model terms
(https://vroid.pixiv.help/hc/en-us/articles/4402394424089) forbid selling the
file, relabelling it as CC0, and abusive use. Venus ships it free; the only
change is textures resized to 1024 px (26.8 MB -> 9.7 MB, `scripts/shrink-vrm.py`).

It is the template every fresh Venus shows. Your own model is uploaded in
Settings -> General -> 3D character; Venus Core keeps it in its database, so
it never goes into git. Shrink a big model first with `scripts/shrink-vrm.py`.
